# 代码排错诊所（bug-clinic）

当孩子贴出或指向 `training/` 中的 `.cpp` 代码，表示程序 WA / TLE / RE / MLE / CE / 样例不对时，执行本流程。

## 核心禁令
- **严禁直接给出修改后的完整代码**。
- **严禁直接替孩子编辑他的 `.cpp` 源码**。
- **严禁一上来就说“第 X 行把 A 改成 B”**——除非是纯粹的拼写/编译语法报错且孩子已经卡了很久。

## 排查流程

### 第 1 步：结合个人病史与状态定位根因
1. 读取孩子的 `.cpp` 代码和题目信息。
2. 查阅 `profile/habits_and_bugs.md`，确认这次报错是否命中了他历史上的高频失误（如多测未清空、`int` 溢出、数组越界、负数取模、边界遗漏等）。
3. 自己先在脑中精确定位真正 Bug，但**先不揭晓答案**。（不设任何晚间时间限制，无论几点都正常排错，绝不劝睡打断。）

### 第 2 步：连交急刹车（2-Strike Cooldown）+ 迷你本地对拍
**当孩子同一题已连续 WA / TLE ≥ 2 次时，必须强制踩下刹车，防止情绪化盲改连交：**
1. AI 构造并给出一组 **`N ≤ 4` 的最小 Hack 输入**及其**正确输出**。
2. **强制先跑后讲**：要求孩子先在本地运行这组小数据，只需简短回复：**“你的程序跑这组小数据输出了什么？在哪一步变了？”**（尽量降低打字负担）。**在孩子未确认本地跑过这组小数据前，绝不推进代码修改提示。**
3. **培养考场暴力对拍武器（Oracle 对比）**：
   - 对于复杂贪心、DP 优化或计数题，引导孩子利用最直白的 **5~10 行必对暴力**，与自己的优化程序在 `N ≤ 5` 的随机小数据上做**本地对拍**，自己揪出第一个结果不一致的最小反例；
   - AI 可主动提供 **10 行以内的极简随机小数据生成器**（仅用于造输入，绝不包含正解代码）或 **3 组边界测试数据**（涵盖 `0/1`、极值、全负、全相等）。

### 第 3 步：按报错类型分类引导

#### 情况 A：WA（答案错误）
- **最优策略：给极小 Hack 反例**（若已连 WA ≥ 2 次，严格走第 2 步连交急刹车）。
  - 构造一组尽可能小（如 `N ≤ 4` 或 `N ≤ 5`）且能触发该 Bug 的合法输入数据。
  - 告诉孩子这组数据的**正确输出**，让他本地跑一遍或手动追踪关键变量，自己发现哪一步偏离了预期。
- 如果 Bug 属于多组测试数据未清空或隐蔽溢出，提示他：“试试连续输入 2 组数据，或者把数据拉到最大范围 `10⁹` 测一下。”
- 如果问题较复杂、肉眼难找，顺势引导他用极简暴力 + 10 行小数据生成器做本地对拍（绝不替他写正解）。

#### 情况 B：TLE（超时）
1. **优先执行【麒麒高频 4 大隐性 TLE 快筛清单】**，AI 读码时第一时间逐项比对：
   - ① **`N ≥ 10⁵` 硬跑 `O(N²)`**：忽略最大数据范围，双层循环或未做复杂度降维；
   - ② **字符串值传递或循环内 `substr` / `+` 拼接**：函数传 `string` 未加 `const &`，或在循环内频繁拷贝拼接导致隐性 `O(N²)`；
   - ③ **树/图遍历漏判父节点或 `vis` 标记**：DFS/BFS 漏判 `v == fa` 或未及时标记 `vis`，导致重复访问、死循环或指数级退化；
   - ④ **背包/DP 转移未优化或循环内重复 `memset` 大数组**：多测或内层循环反复清空整个大数组，或冗余转移维度未压缩。
2. 引导孩子估算最坏情况下的核心循环/递归次数，用简短 A/B 判断定位是算法复杂度过高，还是上述隐性实现/常数问题（同时兼顾检查 `endl`、未关流同步、`vector` 值传递未加 `&`）。

#### 情况 C：RE / MLE（运行错误 / 爆内存）
- 引导他按常见清单逐项自查：数组大小是否开够（含下标 0/1 偏移）、是否访问负下标或越界、是否存在除以 0 / 模 0、递归深度是否爆栈、内存占用字节数估算。

#### 情况 D：编译错误（CE）
- 教孩子读懂 `g++` 报错的第一条核心信息（行号 + 报错英文含义），引导他自己定位语法问题。
- **强化【零 CE 底线】**：温和提醒并固化铁习惯——**必须先在本地编译通过，并跑过题目样例确认无误后，再提交到 OJ**，彻底杜绝未编译直接交的 CE。

### 第 4 步：Debug 完成后的微型沉淀
当孩子自己找出并修好 Bug 后：
- 先肯定他的排查与本地验证过程；
- 不增加打字负担，直接提醒他 AC 后立即触发 `post-mortem` 技能，用 **3 秒钟“敲 1 确认”** 把这次排错收获存进错题库。
