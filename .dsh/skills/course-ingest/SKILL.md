# 老师讲义入库与结构化整理（course-ingest）

本技能主要面向**家长端（Mac mini）**使用，用来把外部非结构化课程资料转化为工作台可检索的“本地教材索引”。

## 执行步骤

1. **读取原始资料**：读取家长指定的 `courses/raw/` 中的文档、文本或图片。
2. **提炼结构化笔记**：在 `courses/notes/` 下创建对应文件，命名格式：`YYYY-MM-DD-<专题简称>.md`（参照总纲 `courses/notes/00-ren-teacher-modeling-playbook.md`），包含以下固定板块：
   - **课程元信息**：日期、专题名称、来源（如任衍硕老师讲义）、关联知识点标签。
   - **核心思想与模型（什么时候想到用它？）**：按任老师五步法（朴素死穴 → 视角转化 → 等价公式与不变量/交换论证微证明）概括；**凡孩子尚未 AC 的待补题，必须使用 `<details><summary>🔒 待补题思路折页（...）</summary>...</details>` 包裹推导结论**，且严禁粘贴完整 `#include` / `int main` AC 代码。
   - **关键模板要点与易错坑**：按任氏验毒四件套记录 `1LL` 防先溢出、整除取整边界、哨兵初值、循环正倒序与入队即标记。
   - **课堂经典例题索引 / 课后巩固题单**：表格第 3 列「题面抽象」与 `适用信号` 只写无剧透题面描述（供教练室第 1 轮定位与「看原题」摘要使用）；题单用 `- [x]` / `- [ ]` 标注真实题号（如 `` `5313` ``、`` `abc484_d` ``）。
   - **公式易读铁律**：笔记全文**严禁写原始 LaTeX 源码**（禁止 `$...$`、`\le`、`\times`、`\frac`），一律使用清晰 Unicode 数学符号与行内反引号（如 `N ≤ 2×10⁵`、`⌊(a - 1) / x⌋`）。
3. **关联能力表（可选）**：询问家长是否需要将该专题补充到 `profile/skill_matrix.md` 中跟踪掌握度。
4. **输出确认**：向家长汇报已生成的笔记文件路径及提炼摘要，提醒可运行 `./scripts/sync_mac.sh` 同步给孩子端。
