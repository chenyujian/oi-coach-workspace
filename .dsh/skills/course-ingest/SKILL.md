# 老师讲义入库与结构化整理（course-ingest）

本技能主要面向**家长端（Mac mini）**使用，用来把外部非结构化课程资料转化为工作台可检索的“本地教材索引”。

## 执行步骤

1. **读取原始资料**：读取家长指定的 `courses/raw/` 中的文档、文本或图片。
2. **提炼结构化笔记**：在 `courses/notes/` 下创建对应文件，命名格式：`YYYY-MM-DD-<专题简称>.md`，包含以下固定板块：
   - **课程元信息**：日期、专题名称、来源（老师讲义/集训课等）、关联知识点标签。
   - **核心思想与模型**：用简洁、孩子易懂的语言概括核心原理与适用条件（什么时候想到用它？）。
   - **关键模板要点与易错坑**：只记关键逻辑与常见坑点（如边界、初始化、复杂度），不盲目堆大段代码。
   - **课堂经典例题索引**：每道例题用 2~3 行记录“题面抽象 + 关键转化点”（方便孩子以后在 OJ 遇到变式题时，AI 提醒他回忆这道例题）。
   - **课后巩固题单（如有）**：列出题目与状态复选框。
3. **关联能力表（可选）**：询问家长是否需要将该专题补充到 `profile/skill_matrix.md` 中跟踪掌握度。
4. **输出确认**：向家长汇报已生成的笔记文件路径及提炼摘要，提醒可运行 `./scripts/sync_mac.sh` 同步给孩子端。
