# 家长端多维学习诊断报告（parent-diagnosis）

本技能主要面向**家长端（Mac mini）**使用，帮助家长在不盯梢的情况下，精准掌握孩子的真实进步与隐藏瓶颈。

## 数据采集范围
执行分析前，先通读以下目录中的最新文件：
1. `mistakes/`（指定时间段内的所有错题卡）
2. `profile/habits_and_bugs.md` 与 `profile/skill_matrix.md`
3. `training/sync_logs/`（如有自动拉取的 AtCoder 等 OJ 提交统计）及 `training/` 下近期练习记录
4. `courses/notes/`（对照近期老师讲过的专题，检查课内知识是否在刷题中落地）

## 报告输出结构
在 `profile/reports/` 下生成独立报告文件（如 `2026-W47.md`），并向家长简要汇报核心发现：

1. **本期训练概览**：练习量、复盘题数、涉及平台与专题分布（若数据不足如实说明，绝不编造）。
2. **四维弱点雷达（核心板块）**：
   - **编程实现（`coding`）**：高频 Bug 类型、稳定性变化趋势。
   - **算法与建模（`algorithm`）**：卡壳集中的模型/知识点、是否存在“听懂讲义但做题认不出”的断层。
   - **数学基础（`math`）**：复杂度分析、计数/数论/取模推导方面的具体短板。
   - **习惯与思维（`habit`）**：审题、手模样例、Debug 策略、对拍意识等方面的观察。
3. **进步亮点**：列出本期明显改善的 1~3 个具体表现（给家长和孩子正向反馈素材）。
4. **下阶段行动建议（给家长的可执行清单）**：
   - 建议优先攻克的 1~2 个薄弱点；
   - 是否需要微调 `AGENTS.md` 或某个 Skill 的提示尺度（例如某个方面 AI 提示偏松或偏紧）；
   - 给孩子的一句简短鼓励/沟通建议。
