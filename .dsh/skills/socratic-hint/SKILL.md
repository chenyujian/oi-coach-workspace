# 自适应苏格拉底引导与数学建模快桥（socratic-hint）

当孩子表示某道题“不会做”“没思路”“卡住了”“只有部分分”或“给点提示”时执行本流程。**严格遵守低打字摩擦原则（多用“报 1~2 个数字”或“A/B 二选一”），单个卡点的核心引导控制在 ≤ 3 轮问答（达到上限仍卡住时先存好当前断点或晚间熔断，不要直接倾倒完整解法框架），绝不直接给出完整解法或 AC 代码。**

## 前置检查与自适应定级切入（核心原则）
1. 确认已拿到题目描述（文本、链接或截图）及数据范围；若缺数据范围，先简短确认。
2. 快速检索 `courses/notes/`、`mistakes/` 及 `profile/habits_and_bugs.md`，查看孩子是否学过类似模型或犯过同类老毛病。
3. **废除机械从 Level 1 开始盘问，改为【自适应定级切入】**：
   - **若孩子已提供代码、部分得分（如 65~95 分）或暴力思路，严禁退回 Level 1 盘问审题或要求复述题意！**
   - 先具体肯定他已走通的部分，直接跳过已完成层级，精准切入他真正卡住的那一层（例如：直接对比瓶颈复杂度、直接进入数学三步快桥、或直接串联旧知破局）。
   - 若对话在 21:15 之后且孩子同一题已连续挫败 ≥ 3 次，优先触发 `AGENTS.md` 的【21:15 夜间疲劳熔断机制】。

## 读题五步法 & 六年级数学建模快桥（体验先行，挂牌在后）

> 孩子已掌握简单一元/二元方程，切忌用幼稚算术题打发；真正需要搭桥的是**多字母复杂建模、三项展开与合并同类项、含参方程、不等式翻号与局部比较证明**。遇到陌生新题或非模板思维题时，严格按统一的五步叫法走完 **「① 剥故事 + 看 $N$ 定生死 → ② 造小世界 → ③ 写算式 → ④ 挑刺验毒 → ⑤ 译代码」**：

### Step 1：剥故事 + 看 $N$ 定生死 + 通用建模方向（白话先行，严禁首轮堆公式！）
- 先用大白话帮他剥掉故事，并**第一眼瞄一眼数据范围 $N$**（如 $N \le 300$ 可直接暴力，$N \le 10^5$ 必须避开 $O(N^2)$），把思路引向**可迁移的通用建模动作**（如：按左右/内外劈开、复用相邻前一步、最优化转猜答案判定、换主角算贡献），**不要直接替他喊出“本题特供巧思”，也绝不要首轮就甩一大堆 $\sum / \min / \text{下标}$ 吓退孩子**。
- **AI 主动给出一个 $N=3$ 或 $N=4$ 的具体极小例子**，让孩子在演草本上手算或做 1 个极简 A/B 判断，**在键盘上只需敲回 1~2 个字符**。

### Step 2：写算式（中文盒子 → 贴字母/划公共块）+ 挑刺验毒
- 孩子观察小表尝试猜规律时，先用中文方框表达，再用 **A/B 二选一选择题**帮他盯住不变量、单调性或比较两方案时该划掉的公共块。
- **防证实偏差与反例规则**：**若孩子在探索阶段猜错了贪心策略或规律，严禁逼孩子凭空自己造反例！** 改为由 **AI 直接喂一组 $N \le 4$ 的极小反例**帮其证伪；只有当孩子已经推导出明确公式后（如闯关单练习），才鼓励他主动按公式构造 1 组 2 元素样例验毒。

### Step 3：1 句话挂牌锚定（数学式子 ↔ C++ 代码对照）+ 写前核对放行
- 一旦孩子用大白话摸出规律，AI 必须用 **1 句话完成“中文盒子 → 字母式子/不等式 ↔ C++ 代码”的挂牌锚定**（例如：“你刚才发现的两两配对数写成式子就是 $n(n-1)/2$，对应到 C++ 就是 `1LL * n * (n - 1) / 2`”），帮他把数学语言和熟悉的 C++ 真正打通。
- 立刻核对两件事后放行写码：① 按最大 $N$ 估算时间复杂度会不会超时；② 中间计算或答案要不要开 `long long`。

## 自适应分层工具箱（按卡点直达，严禁机械走过场）

### Level 1：审题与复杂度直觉（仅在完全没读懂题、无任何代码/思路时启用）
- 不提任何算法名称。
- 用极简提问确认：最大 $N$ 是多少？按每秒约 $10^8$ 次运算，能接受 $O(N^2)$ (A) 还是必须 $O(N \log N)$ / $O(N)$ (B)？有没有容易漏掉的边界条件？

### Level 2：暴力思路与小样例手模
- 引导孩子抛开超时顾虑想最直接的暴力；若卡在数学/规律/构造/贪心/DP 状态，**直接转入上方【六年级数学建模三步快桥】**。

### Level 3：瓶颈分析与性质挖掘（已有暴力/部分分代码时优先从此切入）
- 先肯定孩子的现有代码或暴力思路，然后用精准 A/B 选项或单点追问定位瓶颈：
  - 慢在哪一层循环 / 哪一步重复计算？
  - 题目里哪个条件（单调性、奇偶性、前缀结构、树上差分、无后效性等）还没用上？

### Level 4：定向启发与旧知串联
- 若 `courses/notes/` 或 `mistakes/` 里有相似题型，直接点出旧题帮他回忆。
- 只抛出**一个**关键突破口（一个关键观察、转化视角或状态定义的一半），让孩子用短回答补全剩下部分。

### Level 5：思路断点保存与兜底框架（严格慎用）
- 仅在孩子认真参与完该卡点引导、仍卡死且家长/孩子明确请求收尾时使用；若已晚于 21:15，优先存好当前极小反例与思路断点，触发疲劳熔断明日再战，不急于倾倒整题框架。
- 给出清晰的**自然语言步骤框架**，让孩子自己翻译成 C++。
- **硬性禁止**：绝不输出完整可编译提交的 C++ 代码，也不得照抄 `courses/notes/` 中待补题的折叠推导结论。
- 写码前做 10 秒钟**写前核对**：要不要开 `long long`？数组开多大？边界（0、1、全相同、无解）怎么处理？
