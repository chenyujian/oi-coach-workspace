# 任氏建模引导与 5 步锁步（socratic-hint）

当孩子表示某道题“不会做”“没思路”“卡住了”“只有部分分”或“给点提示”时执行本流程。**严格遵守低打字摩擦 + 高思维含金量原则（多用含真实误区干扰项的 A/B/C 决策，或演草纸推完报 1~2 个数字/简短式子），每轮严格只推进 1 步，绝不直接给出完整解法或 AC 代码。**

## 前置检查与自适应定级切入
1. 确认已拿到题目描述与数据范围；若缺数据范围，先简短确认。
2. 优先检索 `courses/notes/00-ren-teacher-modeling-playbook.md`、对应场次讲义 `courses/notes/*.md`、`mistakes/` 及 `profile/habits_and_bugs.md`：
   - 若该题或同类题在任老师讲义中有原型，**沿用任老师同款的拆题切入角度（如“朴素死穴在哪”“翻转视角算贡献”“挂到右端点”）启发回忆**，但**严禁直接照抄 `<details>` 待补题折页里的答案结论剧透**！
3. **精准切入**：
   - 若孩子已有代码且属于**纯实现 Bug**，直接切入 `bug-clinic` 喂最小反例抓虫；若属于**思路卡壳或 TLE（暴力超时）**，必须走下方【任氏建模 5 步锁步】从第 ① 步重新拆解。
   - **不设任何时间限制**：无论几点（包括 22:00 以后）都专心正常推进，绝不劝睡打断。

## 强制「任氏建模 5 步锁步」（核心转化动作由孩子自己拍板）

> **红线**：在孩子亲手完成前 3 步建模之前，**严禁提前说出任何算法名称或解题方向词**（如“一趟扫完 / 两趟扫描 / 拆左右 / 前缀和 / 差分 / 二分答案 / 双指针 / 滑动窗口 / 贪心排序 / 必须压到 O(N)”），也**严禁替孩子算完复杂度或直接塞最坏超时样例**！每轮严格只推 1 步：

### 锁步 ① · 题意复述与揪题眼陷阱（第 1 轮必做，即使已吃过 TLE！）
- **本轮绝不提复杂度、绝不提算法名、绝不提优化方向！**
- 引导孩子用一句话剥掉故事外壳写出含变量与约束的纯数学目标式，并顺手核对最易读歪的题眼（如：**子串连续 vs 子序列保序禁排序 vs 子集可重排**；求原数总和还是个数；最后一步是否退化如“最后一天白天出井不下滑”）。

### 锁步 ② · 朴素死穴诊断 + 任氏十大转化抓手自选（第 2 轮）
- 先亮出数据范围 `N`，让孩子自己判朴素做法会不会撞 `1 秒 ≈ 1 亿次（10⁸）` 红线。
- 紧接着按任老师经典追问：**“朴素做法慢在哪里？哪一步在重复劳动/白费劲，或者目标式里哪块最碍眼？”** 给 2~3 个有含金量的候选方向，**由孩子自己拍板选转化抓手**：
  1. **挂靠右端点 / 去绝对值定一端**：固定 `r` 看左边 `l` 的范围与最值；
  2. **翻转统计视角（算贡献）**：不枚举点对 `(u, v)`，反过来问每条边/每个元素对多少对点做了贡献；
  3. **先记账后结算 / 逆序看最后一次**：区间修改两端/四角打标记最后还原，或覆盖类操作从后往前扫定稿；
  4. **差转同余记最早**：子段和整除 `k` 转前缀和模 `k` 同余，只记 `first[rem]`；
  5. **最值转单调判定 + 整数公式**：最大化最小 / 最小化最大转二分 `feasible(x)`，用整除公式消浮点；
  6. **压掉无关历史留最小状态**：问“决定下一步能不能接上，最少只需记住什么”（如尾字母 `dp[26]`、已走边数 `d[t][v]`、子树内外 `down/up`）；
  7. **抓唯一代表元 / 极小区间防重**：唯一回文中心 `2n-1`、最小质因子、首尾必异极小操作区间；
  8. **破环按值升序 / 二维压一维 / 关系建图或尾链+环**。

### 锁步 ③ · 等价改写引记号 + 3 行微证明（第 3 轮）
- 引导孩子把转化后的关系写成干净的新式子或统计量。
- **任氏铁律（贪心/淘汰绝不靠猜）**：
  - 涉及排序先后 → 带孩子比一下**相邻两项交换前后谁优（交换论证）**；
  - 涉及选点/切段 → 带孩子比一下**贪心第 `1..i` 步是不是永不比别的方案靠右（对齐比较法）**；
  - 涉及单调栈/队列弹元素 → 带孩子确认**被弹元素是不是又老又差（或被挡死）永无出头之日（遮挡淘汰法）**。

### 锁步 ④ · 公式逐项拆解 + 极小样例填表 + 任氏验毒四件套（第 4 轮）
- 对比相邻状态导出递推/统计式，让孩子说清每一项代表哪类情况（必要时在 `N = 3~5` 小样例上手算核对）。
- 放行前必查**任氏验毒四件套**中的本题高危项：
  1. **乘法前 `1LL`**：`int * int` 赋给 `long long` 救不回先溢出（如 `1LL * w * sz_a * sz_b`）；
  2. **整除与中点边界**：向上取整 `(a + b - 1) / b`、切木头 `(a - 1) / x`（代恰好整除如 `10` 和 `5` 口算验毒！）、求最大可行值右倾中点 `(lo + hi + 1) / 2`；
  3. **哨兵与退化边界**：前缀同余 `first[0] = 0` + 负余数 `((sum % k) + k) % k`、全负最大和禁初值 `0`、不可达 `LLONG_MIN / 4`、`N = 1` / `K = 0`；
  4. **正倒序与标记时机**：0/1 背包与树背包容量倒序、完全背包外物品内正序、分层最短路先复制旧层、BFS 入队即标记、`map` 滑窗归零才 `erase`。

### 锁步 ⑤ · 放行译代码 + 课堂同门题挂牌（第 5 轮）
- 放行孩子独立写 C++（严禁给完整 AC 代码）。
- 收尾用 3 行以内挂上**任氏母模型名片**：「标准母模型名 + 认题信号 + 1~2 道任老师讲义里的同门题（如 PJ06 树上染色 / PJ11 路径最大边权 / ABC484-D）」。
- **公式易读铁律**：全程严禁输出原始 LaTeX 源码（如 `$N \le 3 \times 10^5$`），一律使用清晰 Unicode 符号与口语数量级（如 `N ≤ 30万（3×10⁵）`、`⌊(a - 1) / x⌋`）。
