# 苏格拉底五级渐进提示工作流（socratic-hint）

当孩子表示某道题“不会做”“没思路”“卡住了”或“给点提示”时，严格按以下阶梯逐步引导。**每一轮只推进一个层级，必须等孩子回应后再决定是否进入下一层。**

## 前置检查
1. 确认已经拿到题目描述（文本、链接或截图）以及数据范围。如果缺少数据范围，先向孩子确认。
2. 快速检索 `courses/notes/` 和 `mistakes/`，查看孩子之前是否学过类似模型或做过同类型错题。

## 五级提示阶梯

### Level 1：审题与复杂度直觉
- 不要讲任何算法名称。
- 让孩子用 1~2 句话复述题目核心要求，并回答：
  - 数据范围最大是多少？按每秒约 $10^8$ 次基本运算，大概能接受什么时间复杂度？
  - 题目里有没有容易忽略的限制条件或特殊情况？

### Level 2：暴力思路与手模小样例
- 引导孩子先抛开时间限制：“如果不考虑超时，最笨、最直接的暴力做法怎么算？”
- 如果连暴力都没思路，构造一个极小的例子（例如 $N=3$ 或 $N=4$），引导孩子手动模拟一遍找规律。

### Level 3：瓶颈分析与性质挖掘
- 肯定孩子的暴力思路，然后追问：
  - “你的暴力做法慢在哪一层循环 / 哪一步重复计算？”
  - “题目里有没有某个性质（单调性、奇偶性、前缀结构、无后效性、图/树结构等）我们刚才完全没用上？”

### Level 4：定向启发与旧知串联
- 如果 `courses/notes/` 或 `mistakes/` 里有相似题型，明确提醒他回想那次的方法。
- 只抛出**一个**关键突破口（例如：一个关键观察、一种问题转化视角、或者状态定义的一半），让孩子自己补全剩下部分（例如转移方程、贪心策略或数据结构选型）。

### Level 5：思路框架与边界自查（底线）
- 仅在孩子认真参与前几轮讨论后依然卡死时使用。
- 给出清晰的**自然语言步骤框架**或极简数学公式/伪代码逻辑，让孩子自己翻译成 C++。
- **硬性禁止**：绝不输出完整可编译提交的 C++ 代码。
- 孩子准备开始写代码前，提醒他做一次简短的**写前核对**：变量类型要不要开 `long long`？数组开多大？边界（如 0、1、全相同、无解）怎么处理？
