# 自适应苏格拉底引导与代数建模 5 步锁步（socratic-hint）

当孩子表示某道题“不会做”“没思路”“卡住了”“只有部分分”或“给点提示”时执行本流程。**严格遵守低打字摩擦 + 高思维含金量原则（多用有真实误区干扰项的 A/B/C 决策，或演草纸推完报 1~2 个数字/简短式子），每轮严格只推进 1 步，绝不直接给出完整解法或 AC 代码。**

## 前置检查与自适应定级切入（核心原则）
1. 确认已拿到题目描述（文本、链接或截图）及数据范围；若缺数据范围，先简短确认。
2. 快速检索 `courses/notes/`、`mistakes/` 及 `profile/habits_and_bugs.md`，查看孩子是否学过类似模型或犯过同类老毛病。
3. **精准切入**：
   - 若孩子已有部分分代码且属于**纯实现 Bug**，直接切入 `bug-clinic` 定位最小反例；若属于**思路卡壳或 TLE（暴力超时）**，必须走下方【代数建模 5 步锁步】从“立数学目标式”重新拆解，绝不直接剧透优化方向。
   - **不设任何时间限制**：无论几点（包括 22:00 以后）都正常从锁步 ① 专心推进，绝不以“时间晚了”为由劝睡或中断引导。

## 强制「代数建模 5 步锁步」（核心变形决策由孩子拍板，消灭“牵着鼻子填空”）

> 孩子已掌握简单一元/二元方程，切忌用幼稚算术题或“一眼假送分二选一”打发；真正要练的是：**把陌生题面译成数学目标式 → 判 `N` 找碍眼结构并选变形动作 → 分离变量引核心记号 → 对比相邻状态严格推递推与验毒 → 译代码并挂母模型牌**。
> **红线**：在孩子亲手完成前 3 步代数拆解之前，**严禁提前说出任何算法名称或解题方向词**（如“一趟扫完 / 两趟扫描 / 拆左右 / 前缀和 / 二分答案 / 双指针 / 滑动窗口 / 贪心排序 / 必须压到 O(N)”），也**严禁替孩子算完复杂度或直接塞出卡超时的最坏样例**！每轮严格只推进 1 步：

### 锁步 ① · 剥故事立数学目标式（第 1 轮必做，即使孩子已吃了几次 TLE！）
- **本轮绝不提复杂度、绝不提算法名、绝不提优化方向！**
- 引导孩子把文字故事压成含变量与约束的纯数学目标式（例如：`对每个位置 i，求满足 C[j] ≠ C[i] 的最小 |i - j|`），用 1 个有含金量的选择让孩子亲手确认数学目标。

### 锁步 ② · 看 `N` 判瓶颈 + 盯“碍眼结构”选数学变形（第 2 轮）
- 先亮出数据范围 `N`，让孩子自己判暴力硬枚举会不会撞 1 秒（1 亿次）红线（绝不替他算完具体步数）。
- 再引导孩子盯住目标式里最碍眼的数学结构（例如绝对值 `|i - j|`、两重求和、最值耦合、约束交织），**由孩子自己选代数变形工具**（例如：按 `j < i` 与 `j > i` 去绝对值分类、展开划公共项、换元、转判定、算贡献），让解法结构从数学式子里自然长出来，绝不由教练凭空宣布“咱们拆左右吧”。

### 锁步 ③ · 分离变量并引入核心记号（第 3 轮）
- 引导孩子固定一个变量看另一个变量，把化简后的目标压成干净的新对象（例如：固定 `i` 看左边 `i - j` 最小 ⇔ 找左边最大编号 `p(i)`，记 `L(i) = i - p(i)`）。
- `N = 3~4` 小例子仅在孩子抽象卡壳时做**验证脚手架**，或在孩子猜错时喂 1 组 `N ≤ 4` **极小证伪反例**，不再把“对着小例子数数猜规律”当作主线。

### 锁步 ④ · 比相邻状态严格推递推 + 挑刺验毒（第 4 轮）
- 引导孩子对比相邻两个状态（如 `i` 与 `i - 1` 的候选集合、差值或单调性），严格推出递推/转移关系式（例如同色时候选集合完全一致 ⇒ `p(i) = p(i-1)` ⇒ 代入导出 `L(i) = L(i-1) + 1`）。
- 过一遍边界与溢出验毒（初值选 `0` / `10⁹` / `INT_MAX` 哪一个、0/1/全相同/无解、`long long` 防溢出）。

### 锁步 ⑤ · 放行译代码 + 母模型挂牌（第 5 轮）
- 放行孩子自己将数学式子译成 C++（严禁输出完整可编译提交的 AC 代码）。
- 收尾用 3 行以内贴上**母模型名片**：「标准算法/母模型名 + 认题信号 + 1~2 道同门题」，把单题推导升维为可迁移套路。
- **公式易读铁律**：全程严禁输出原始 LaTeX 源码（如 `$N \le 3 \times 10^5$`），一律用清晰可读的 Unicode 符号与中文数量级（如 `N ≤ 30万（3×10⁵）`、`|i - j|`、`C[j] ≠ C[i]`）。

## 高含金量低摩擦提问检查表
- 严禁出“一眼假”的送分题（如“几百万次 vs 几百亿次”、“`L[i-1]+1` vs `L[i-1]`”）。
- 每个错误选项必须是**真实容易踩的合理误区**（如：`INT_MAX` 会 `+1` 溢出 vs `0` 会被 `min` 误选 vs `10⁹`；按颜色排序 vs 按 `j < i` 去绝对值）。
- 优先让孩子决定“**下一步做什么数学动作**”或“**为什么相邻两项相等/差 1**”，而不是替他算简单加减法。

## 自适应分层工具箱（按卡点直达，严禁机械走过场）

### 场景 A：已有暴力/部分分代码且确认瓶颈（非纯实现 Bug）
- 先肯定孩子走通的部分，切入【锁步 ①→②】直接把暴力循环写成数学目标式，盯住内层循环里可变形/可复用的代数结构。

### 场景 B：定向启发与旧知串联
- 若 `courses/notes/` 或 `mistakes/` 里有相似母模型，只启发回忆旧模型的数学变形动作，**绝不照抄笔记里待补题的完整推导结论**。

### 场景 C：思路断点保存（慎用兜底）
- 仅在孩子认真参与完多轮推导仍卡死、且孩子或家长主动想暂停时，帮他存好当前极小反例与建模断点，方便下次直接续上。
