## 核心思想与模型（什么时候想到用它？）

### 1. 最后一步退化拆解法：蜗牛爬井不等式（T1 · 已 AC）
- **任氏建模**：最后一天白天爬到井口就出去了，**不再下滑**！因此不能直接算 `H / (a - b)`，必须拆成“前 `d - 1` 个完整昼夜净升 `(d - 1)(a - b)` + 第 `d` 天白天 `+a` ≥ `H`”：
  - `H ≤ a` 时 `d = 1`；否则 `d = 1 + ⌈(H - a) / (a - b)⌉ = 1 + (H - a + a - b - 1) / (a - b)`。

### 2. T3 最长回文子串计数（`5250` · 待补重点）

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **适用信号**：`|s| ≤ 2000`，求最长回文子串长度，以及达到该最大长度的位置不同子串个数。
- **任氏核心模型**：抓唯一代表元：枚举 `2n - 1` 个回文中心
- **任氏核心性质（每个回文子串有且仅有唯一中心）**：
  - 奇数长回文（如 `bab`）：中心在正中间字符 `(i, i)` 上（共 `n` 个）；
  - 偶数长回文（如 `abba`）：中心在正中间两字符间隙 `(i, i + 1)` 上（共 `n - 1` 个）。
- **推论与 86 分查错指南**：
  - 枚举全部 `2n - 1` 个中心向两侧极长扩展，失配停下时回退一步得长度 **`len = r - l - 1`**；
  - 因为每个中心最多扩出一个达到全局最大长度 `best` 的回文（同一中心若更短就不是 `best`，若更长已扩到头），所以**扩出长度等于 `best` 的中心个数，不重不漏就是最长回文子串个数**！
  - **高频 86 分坑点**：① 漏了偶数中心 `(i, i + 1)` 或奇数中心；② `len > best` 时重置 `best = len, cnt = 1`，`len == best` 时 `cnt++` 两个分支缺一或初值错误；③ `|s| = 1` 或全异字符如 `abcd` 时应输出 `1 4`。

</details>

### 3. T4 黑板擦写（`5251` · 待补题）

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **适用信号**：`n×m` 网格（`≤ 1000`）执行 `q ≤ 10⁵` 次子矩形 `[x₁..x₂] × [y₁..y₂]` 整体 `+1`，最后求最大格值。
- **任氏核心模型**：从一维两端到二维四角容斥：二维差分与前缀和还原
- **任氏建模（一维差分升维）**：
  1. **四角容斥打标记**：`d[x1][y1] += 1`（左上开启），`d[x2+1][y1] -= 1`（下边界外撤回），`d[x1][y2+1] -= 1`（右边界外撤回），**`d[x2+1][y2+1] += 1`**（右下角被撤了两次，补回一次 `+1`）。
  2. **二维前缀和还原**：`d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1]`。
  3. **防越界铁律**：会写到 `x2 + 1` 和 `y2 + 1`（可达 `1001`），数组必须多开一圈（如 `1005×1005`）！

</details>

### 4. 二维压一维：枚举行上下界 + 列和 Kadane（T5 最大子矩阵和 · 已 AC）
- **任氏建模**：四条边枚举 `O(n²m²)` 超时；固定上下行 `[top, bot]`（`O(n²)`），用列前缀和 `O(1)` 压成一维数组 `colsum[j]`，转化为一维最大非空子段和 `cur = max(colsum[j], cur + colsum[j])`（**全负矩阵不能选空段，初值绝不能设 `0`！**）。

### 5. T6 小红造公园（`5253` · 待补重点）

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **适用信号**：森林初始 `m < n ≤ 3×10⁵` 条边，支持查询点所在树直径，或连一条边合并两棵树使**新树直径尽可能小**。
- **任氏核心模型**：只维护连通块直径：中点相连最小化新直径
- **任氏建模两步曲**：
  1. **初始各树直径**：树形 DP 对每棵树扫一遍，维护往下最长链 `down[u]`，在每个点用“最长子链 + 次长子链”刷新该连通块直径 `d`。
  2. **连哪里新直径最小？（取各自直径中点！）**：
     - 在直径为 `d` 的树上选一个连接点，树内任意点到该连接点的最大距离最小是 **`⌈d / 2⌉ = (d + 1) / 2`**（即直径中点）。
     - 把直径为 `d_x, d_y` 的两块中点用 1 条新边连起来，跨块最长路径为 `⌈d_x / 2⌉ + ⌈d_y / 2⌉ + 1`，且原块内部直径不会缩小！
     - **一行合并公式**（并查集每个根只需存一个整数 `diam[root]`，根本不用真的在图上加边重跑 DFS！）：
       `diam_new = max({ d_x, d_y, (d_x + 1) / 2 + (d_y + 1) / 2 + 1 })`。

</details>

## 关键模板要点与易错坑

- **T1 蜗牛爬井**：必须特判 `H <= a` 直接第 1 天出井。
- **T2 排名次**：`std::sort` 不保证稳定，并列时编号升序必须显式写进比较器。
- **T5 最大子矩阵和**：Kadane 初值设为 `colsum[1]` 而非 `0`。

<details>
<summary>🔒 待补题写码验毒清单（独立完成建模或排查 WA/TLE 时展开核对）</summary>

- **T3 最长回文子串计数**：中心扩展返回 `r - l - 1`；奇偶两类中心缺一不可。
- **T4 黑板擦写**：四角符号 `+ - - +` 与还原容斥 `+ + -` 别混，数组开到 `1005`。
- **T6 小红造公园**：① 若 `find(x) == find(y)` 已连通，必须直接跳过忽略，不能套合并公式把自身直径变大！② 孤立单点的初始直径是 `0`（不是 `1`），合并两个单点得 `max(0, 0, 0 + 0 + 1) = 1`。

</details>
