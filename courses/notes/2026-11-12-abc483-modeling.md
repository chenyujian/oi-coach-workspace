## 核心思想与模型（什么时候想到用它？）

### 1. 正负号一体编码牌面与正反（B `abc483_b` · 已 1A）
- **任氏状态表示技巧**：用正数 `+X` 表示正面朝上、负数 `-X` 表示背面朝上，整叠顶 `K` 张翻面放回直接变成“前 `K` 项逆序并全体取负”，省掉第二个布尔数组。

### 2. 缩小候选集 + 局部差分回滚均摊 `O(N + M)`（C `abc483_c` · 已 1A）
- **任氏建模**：先算无人退选时的冠亚军 `X, Y`。当候选人 `k` 退选时，只有 `k` 的 `N_k` 名第一顺位支持者改投第二选择 `c₁..c_{N_k}`，其余人票数不变且原本就输给未退选的 `X` 或 `Y`！因此每轮只需临时加票、只检查 **`{X, Y, c₁..c_{N_k}}` 这 `N_k + 2` 个候选人**，测完立刻撤销恢复，`∑N_k = M` 严格线性！

### 3. 翻转一步最大化覆盖坐标数：神仙点菜立最值 + 抄邻居作业（D `abc483_d` Glitchy Robot · 已补题 AC！）

- **适用信号**：从坐标 `0` 出发依次按步长 `A₁..A_N` 移动，可至多将其中 1 步 `A_k` 反号变为 `-A_k`，求全过程最多能踏上多少个不同的整数坐标。
- **任氏三步建模拆解**：
  1. **剥壳 + 神仙点菜立量**：每次直线移动经过的整数点是连续闭区间，个数恒为 **`maxPos - minPos + 1`**，极值只出现在每步结束的脚印 `S₀, S₁, …, S_N` 上。翻第 `k` 步后，前段 `0..k-1` 脚印不动、后段 `k..N` 整体平移 **`-2·A_k`**。因此只要向神仙点两道菜——前段最值 `preMax[k-1] = max(S[0..k-1])` 与后段最值 `sufMax[k] = max(S[k..N])`（`preMin / sufMin` 同理），翻第 `k` 步的答案就能一行算出：`max(preMax[k-1], sufMax[k] - 2×A[k]) - min(preMin[k-1], sufMin[k] - 2×A[k]) + 1`（别漏不翻转的基准值 `preMax[N] - preMin[N] + 1`！）。
  2. **抄邻居作业逼出正倒扫**：按定义硬算要 `O(N²)`；改看相邻关系——`preMax[k] = max(preMax[k-1], S[k])`（抄左边 `k-1` 的作业 → **被迫正着扫**，注意 `k` 从 `1` 开始防漏 `k=1`！）；`sufMax[k] = max(sufMax[k+1], S[k])`（抄右边 `k+1` 的作业 → **被迫倒着扫**，初值 `sufMax[N] = S[N]` 严禁设 `0`！）。
  3. **任老师解法二（`O(1)` 空间相对偏移 DP）**：维护尚未翻转的最大/最小相对偏移 `mx0, mn0` 与至多翻转 1 次的 `mx1, mn1`（初值全 `0`）；每步读入 `x = Aᵢ`：`mx1 = max(mx1 - x, mx0 + |x|)`、`mn1 = min(mn1 - x, mn0 - |x|)`、`mx0 = max(0LL, mx0 - x)`、`mn0 = min(0LL, mn0 - x)`，用 `max(mx1, -mn1)` 刷新最大跨度，最终输出 `ans + 1`（全程 `long long`）。

### 4. E `abc483_e` Typo Pairs（待补题）

- **适用信号**：`N ≤ 2×10⁵` 个长 `M ≤ 6` 字符串，统计汉明距离 `≤ 2`（至多 2 位不同）的无序对 `(i, j)` 数。

- **任氏核心模型**：汉明距离 `≤ 2`：扣字符哈希分桶 + 容斥系数反推
- **任氏多重计数反推系数法**：
  - 统计三类好算的集合大小：全相等对数 `|A|`、删去第 `k` 位后相等对数 `∑|B_k|`、删去第 `(k, k')` 两位后相等对数 `∑|C_{k,k'}|`（相同串出现 `x` 次贡献 `x(x-1)/2` 对）。
  - 数清每种真实汉明距离 `d ∈ {0, 1, 2, ≥3}` 在三类和中各被数了几次，配线性组合系数：
    `Ans = C(M-1, 2)·|A| - (M - 2)·∑|B_k| + ∑|C_{k,k'}|`，使 `d = 0, 1, 2` 恰好各计 **1 次**、`d ≥ 3` 计 **0 次**！
