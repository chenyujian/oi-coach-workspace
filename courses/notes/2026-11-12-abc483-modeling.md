## 核心思想与模型（什么时候想到用它？）

### 1. 正负号一体编码牌面与正反（B `abc483_b` · 已 1A）
- **任氏状态表示技巧**：用正数 `+X` 表示正面朝上、负数 `-X` 表示背面朝上，整叠顶 `K` 张翻面放回直接变成“前 `K` 项逆序并全体取负”，省掉第二个布尔数组。

### 2. 缩小候选集 + 局部差分回滚均摊 `O(N + M)`（C `abc483_c` · 已 1A）
- **任氏建模**：先算无人退选时的冠亚军 `X, Y`。当候选人 `k` 退选时，只有 `k` 的 `N_k` 名第一顺位支持者改投第二选择 `c₁..c_{N_k}`，其余人票数不变且原本就输给未退选的 `X` 或 `Y`！因此每轮只需临时加票、只检查 **`{X, Y, c₁..c_{N_k}}` 这 `N_k + 2` 个候选人**，测完立刻撤销恢复，`∑N_k = M` 严格线性！

### 3. D `abc483_d` Glitchy Robot（待补重点）

- **适用信号**：从坐标 `0` 出发依次按步长 `A₁..A_N` 移动，可至多将其中 1 步 `A_k` 反号变为 `-A_k`，求全过程最多能踏上多少个不同的整数坐标。

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **任氏核心模型**：翻转一步最大化覆盖坐标数：前后缀平移法 & 相对偏移 DP
- **第 1 步（剥掉连续移动外壳）**：每次直线移动不折返，经过的所有整数点必然是某段连续闭区间 `[minPos, maxPos]`，个数恒为 **`maxPos - minPos + 1`**，而极值只可能出现在每步结束的折点前缀和 `S₀, S₁, …, S_N` 上！
- **解法一（枚举翻转位置 `k` + 前后缀最值平移）**：
  - 将 `A_k` 翻成 `-A_k` 后：
    - 对 `0 ≤ i < k`：前缀和 `Sᵢ` **完全不变**；
    - 对 `k ≤ i ≤ N`：每个前缀和统一平移成 **`Sᵢ - 2·A_k`**！
  - 预处理 `M_Left[k] = max_{0..k-1} Sᵢ`、`M_Right[k] = max_{k..N} Sᵢ`（以及对应的 `m_Left, m_Right`），翻转 `k` 后的坐标数一行算出：
    `max(M_Left[k], M_Right[k] - 2*A_k) - min(m_Left[k], m_Right[k] - 2*A_k) + 1`！（别漏“一个都不翻”的基准值 `M_Right[0] - m_Right[0] + 1`！）
- **解法二（任老师补充 `O(1)` 空间动态规划：维护历史点相对当前位置的偏移）**：
  - 维护尚未翻转的最大/最小相对偏移 `mx0, mn0` 与至多翻转 1 次的 `mx1, mn1`（初值全 `0`）；
  - 每步读入 `x = Aᵢ`：
    - `mx1 = max(mx1 - x, mx0 + |x|)`，`mn1 = min(mn1 - x, mn0 - |x|)`；
    - `mx0 = max(0LL, mx0 - x)`，`mn0 = min(0LL, mn0 - x)`；
    - 用 `max(mx1, -mn1)` 刷新最大跨度 `ans`，最后输出 `ans + 1`（全程注意 `long long`！）。

</details>

### 4. E `abc483_e` Typo Pairs（待补题）

- **适用信号**：`N ≤ 2×10⁵` 个长 `M ≤ 6` 字符串，统计汉明距离 `≤ 2`（至多 2 位不同）的无序对 `(i, j)` 数。

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **任氏核心模型**：汉明距离 `≤ 2`：扣字符哈希分桶 + 容斥系数反推
- **任氏多重计数反推系数法**：
  - 统计三类好算的集合大小：全相等对数 `|A|`、删去第 `k` 位后相等对数 `∑|B_k|`、删去第 `(k, k')` 两位后相等对数 `∑|C_{k,k'}|`（相同串出现 `x` 次贡献 `x(x-1)/2` 对）。
  - 数清每种真实汉明距离 `d ∈ {0, 1, 2, ≥3}` 在三类和中各被数了几次，配线性组合系数：
    `Ans = C(M-1, 2)·|A| - (M - 2)·∑|B_k| + ∑|C_{k,k'}|`，使 `d = 0, 1, 2` 恰好各计 **1 次**、`d ≥ 3` 计 **0 次**！

</details>
