## 核心思想与模型（什么时候想到用它？）

### 1. 相邻交换论证：短任务优先排队（T2 打印排队 · 已 AC）
- **任氏建模**：若相邻两人 `tᵢ > tⱼ`，交换两人对前后其他人无影响，而两人内部等待时间从 `tᵢ` 降为 `tⱼ`（净减 `tᵢ - tⱼ > 0`）。故按 `t` 升序排列最优；注意第 1 个人等待时间为 `0`，答案可达 `5×10¹²` 用 `long long`。

### 2. T3 环形分糖（`5219` · 待补重点）

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **适用信号**：`n` 个孩子**围成一圈**，每人至少 1 颗糖，分数严格高于相邻孩子时糖数必须更多（分数相等无约束），求最少总糖数。
- **任氏核心模型**：环形让“两趟扫描”失灵 → 改按值域升序发糖
- **为什么直线版的“左右两趟扫描”在环上会错（40 分根因）？**
  - 直线有左右两个无约束端点兜底；圆圈没有端点！随便挑一处断开扫两趟，断口两端的约束会漏掉（例如圆圈 `3, 1, 2`：1 号 `3` 分同时高于 2 号 `1` 分和 3 号 `2` 分，最少是 `3 + 1 + 2 = 6` 颗，断开扫会错算成 `5` 颗）。
- **任氏破环建模（从“按位置扫”切换为“按分数从低到高定稿”）**：
  1. **不排数据排下标**：建 `ord = {0, 1, …, n-1}` 按表现分 `r[i]` 升序排序（保留原环上左右邻居 `(i + n - 1) % n` 与 `(i + 1) % n` 的位置关系）。
  2. **按 `ord` 从小到大发糖**：每人初值 `1`；轮到孩子 `i` 时，所有分数**严格低于 `r[i]`** 的邻居必定已经发完糖定稿了！直接令 `c[i] = max`（所有 `r[nb] < r[i]` 的邻居 `c[nb] + 1`），相等分数的邻居无约束直接跳过。
  3. **为什么最优？** 沿任意严格下降链的下界全被满足且处处紧贴下界，依赖图严格由小指向大、绝不生环！

</details>

### 3. T4 逆序对（`5220` · 待补重点）

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **适用信号**：统计满足 `i < j` 且 `a[i] > a[j]` 的数对总数（`n ≤ 10⁵`）。
- **任氏核心模型**：分治顺手数跨半区贡献：归并排序求逆序对
- **任氏分治建模**：把逆序对按位置不重不漏分成三类：全在左半 `[l, m)`、全在右半 `[m, r)`、一左一右跨中点。
  - 前两类递归解决；
  - 合并两个已升序的半区时，左半下标天然 `<` 右半下标！当右半元素 `a[j]` 因严格小于 `a[i]` 被先取走时，由于左半递增，**左半剩余的 `[i, m)` 全部严格大于 `a[j]`**，一行累加 `ans += m - i`！
- **两个决定对错的细节**：
  1. **相等不构成逆序对**：合并比较必须写 **`a[i] <= a[j]`** 让左半先走，漏掉等号会把相等元素误算进逆序对！
  2. **答案上界**：逆序排列有 `n(n-1)/2 ≈ 5×10⁹` 对，爆 `int`（只拿 7 分的常见原因之一），`ans` 必须开 `long long`！

</details>

### 4. 把整数看成点、操作看成边：状态图无权 BFS（T5 数字变换 · 已 AC）
- **任氏建模**：`+1, -1, ×2` 三种操作代价都是 `1`，把 `0 ~ 2×10⁵` 每个整数看作顶点跑 BFS 逐层扩展，首次到达 `B` 的层数即最少步数（严禁越出 `[0, 2×10⁵]`，入队即标 `dist` 防 `+1/-1` 死循环震荡）。

### 5. T6 数字花园的修剪游戏（`5222` · 提高拓展）

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **适用信号**：动态删最左二进制子串并维护当前下标与次数。
- **任氏核心模型**：图案转二进制编号 + 树状数组排名 + 断口局部重算
- **核心观察**：① 无前导零二进制串与正整数 `1..n` 一一对应，且 `n ≤ 10⁶ < 2²⁰` 意味着窗口长度最多 **20 位**！只要跳过以 `'0'` 开头的窗口，每个长度 `1..20` 窗口的二进制数值就是它的唯一编号；② 剪掉一段后剩余草相对顺序不变，“当前下标 = 原始坐标在存活草中的前缀和排名”（树状数组维护存活 `0/1` + 倍增 `kth` 定位）；③ 每次剪掉长 `L ≤ 20` 的一段，只有断口左侧 `L - 1` 个起点和被剪的 `L` 个起点受影响，双小根堆惰性删除局部更新仅需 `O(L log n)`。

</details>

## 关键模板要点与易错坑

- **T1 密码强度**：布尔标志直接相加 `int k = hasDigit + hasLower + hasUpper + hasSymbol`；长度 `< 8` **或** `k ≤ 1` 均为 `weak`。
- **T2 打印排队**：先 `total += wait` 再 `wait += t[i]`，顺序写反会把自己的打印时间算进自己的等待时间。
- **T5 数字变换**：`x = 0` 时 `x - 1 = -1` 越界，扩展邻居前先判 `0 <= y && y <= LIM`。

- **T4 逆序对（7分冲百关键）**：检查 `long long ans = 0` 与归并条件 `a[i] <= a[j]`。
