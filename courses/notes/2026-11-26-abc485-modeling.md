## 核心思想与模型（什么时候想到用它？）

### 1. 同侧判别式与整表模拟（A `abc485_a` & B `abc485_b` · 已 1A）
- **`abc485_a` Same Side**：同正或同负等价于乘积 `A × B > 0`（坐标非零且不大，直接一行判定）。
- **`abc485_b` Faucets and Drains**：`N, M ≤ 100`，可能故障源总共只有 `N + M` 个，逐个假设“第 `i` 个水龙头坏（该行全 `x` 其余全 `o`）”或“第 `j` 个排水口坏（该列全 `x` 其余全 `o`）”生成整表比对，`O((N + M)NM)` 稳过。

### 2. 任氏底层母法典范：神仙点菜立同色边界 + 抄邻居作业（C `abc485_c` Different Neighbor · 已补题 AC！）
- **第 ① 步（神仙点菜立边界量）**：题目问点 `i` 到最近异色点的距离，反过来立**包含点 `i` 的极大同色区间左右端点 `L[i], R[i]`**。只要知道 `L[i], R[i]`，门外紧挨的 `L[i] - 1`（若 `L[i] ≠ 1`）和 `R[i] + 1`（若 `R[i] ≠ N`）必为最近异色点，答案直接是 `min(i - L[i] + 1, R[i] + 1 - i)`！
- **第 ② 步（承认硬算超时）**：对每个 `i` 各自向左右硬扩求 `L[i], R[i]` 最坏 `Θ(N²)`（`N ≤ 3×10⁵` 必 TLE）。
- **第 ③ 步（抄邻居作业逼出正倒扫）**：
  - 看 `L[i]` 与左边邻居 `i - 1`：当 `i ≥ 2` 时，若 `C[i] == C[i - 1]` 则直接抄左边 **`L[i] = L[i - 1]`**，否则 `L[i] = i` ⇒ 因为依赖 `i - 1`，**被迫从左往右正着扫一遍**；
  - 看 `R[i]` 与右边邻居 `i + 1`：当 `i ≤ N - 1` 时，若 `C[i] == C[i + 1]` 则直接抄右边 **`R[i] = R[i + 1]`**，否则 `R[i] = i` ⇒ 因为依赖 `i + 1`，**被迫从右往左倒着扫一遍**！

### 3. D `abc485_d` ABC|ABC|ABC（待补重点）

- **适用信号**：给定长度 `N ≤ 3×10⁵`、仅由 `A / B / C` 组成的字符串 `S`，选两处切口 `1 ≤ i < j < N` 将 `S` 切成三段非空子串，求三段**各自都同时包含 A、B、C** 的切分方式总数。

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **任氏核心模型**：三段边界解耦 + 单调指针函数 `f(l)`（解法一） / 状压线性 DP（解法二）
- **解法一（神仙点菜立三量 + 抄邻居单调性导出尺取法）**：
  1. **立左/右两头门槛 `L, R`**：设 `L` 为使前段 `S[1..L]` 集齐 `A, B, C` 的最小位置（正扫找第一个）；设 `R` 为使后段 `S[R+1..N]` 集齐 `A, B, C` 的最大切口位置（倒扫找第一个）。若不存在则答案为 `0`。于是左右两段同时达标 ⇔ **`L ≤ i` 且 `j ≤ R`**！
  2. **立中间最早右刀函数 `f(l)`**：固定左刀 `i = l`（`L ≤ l ≤ R`），设 `f(l)` 为使中间段 `S[l+1..r]` 集齐 `A, B, C` 的最小右刀 `r ≤ R`（不存在记为 `R + 1`）。只要知道 `f(l)`，合法右刀 `j` 就是 `f(l) ≤ j ≤ R`，个数直接为 **`R - f(l) + 1`**！
  3. **抄邻居作业导出双指针**：左刀从 `l` 挪到 `l + 1` 时，中间段丢掉 1 个字符，最早集齐 `A, B, C` 的右刀只会更靠右或不变（**`f(l) ≤ f(l + 1)` 单调不退**）！因此不用每次从头找 `r`，接着上次的 `r` 继续往右推即可，`O(N)` 累加 `long long` 答案！
- **解法二（状态瘦身 DP）**：
  - 定义 `dp[i][j][mask]`：处理完前 `i` 个字符、已切了 `j ∈ {0, 1, 2}` 刀、当前所在段已收集的字符集合为 `mask ∈ [0..7]`（`A=1, B=2, C=4`）的方案数。
  - 每读 1 个字符把对应位或进 `mask`：`nextMask = mask | bit(c)`；先继承不切 `ep[j][nextMask] += dp[j][mask]`；若 `j ≤ 1` 且 `nextMask == 7`（当前段已集齐 ABC），允许在此切一刀进入下一空段：`ep[j + 1][0] += dp[j][mask]`。最终输出 `dp[2][7]`，`O(N)`（记得开 `long long`！）。

</details>

### 4. E `abc485_e` Colorful Route（待补题）

- **适用信号**：`N, M ≤ 2×10⁵` 的有向图，每条边有颜色 `Cᵢ`，求从点 `1` 到点 `N` 且**不能连续走两条同色边**的最少经过边数（不可达输出 `-1`）。

<details>
<summary>🔒 待补题思路折页（独立思考并手模 15 分钟前请勿展开；孩子端 AI 教练严禁直接照抄原文剧透）</summary>

- **任氏核心模型**：异色边约束无权最短路：每个点只需保留“最优 + 异色次优”两档状态跑 BFS
- **为什么不用把所有颜色塞进状态？** 到达点 `v` 后，出边只关心“我能不能避开某种颜色 `c`”。因此对每个点 `v`，只需要维护 3 个量：
  - `D₀(v)`：到达 `v` 的最短路长度；
  - `C(v)`：达到 `D₀(v)` 时最后那条边的颜色；
  - `D₁(v)`：最后一条边颜色 **不等于 `C(v)`** 的最短路长度。
- **正确性与复杂度**：若从 `v` 要走颜色为 `c` 的出边，只要 `c ≠ C(v)` 用 `D₀(v)` 必最优，若 `c == C(v)` 则必须且只需用异色最优 `D₁(v)`，第 3 种颜色永远没用！BFS 中每个点最多入队 **2 次**、每条边最多被松弛 **2 次**，严格 `O(N + M)`！

</details>
