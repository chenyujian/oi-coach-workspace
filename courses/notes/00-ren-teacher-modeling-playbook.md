## 零、给六年级选手的建模破冰：什么叫“数学建模”？

不要被黑板或讲义上满屏的 `i, j, l, r`、向下取整和不等式吓到！**数学建模绝对不是背诵高深公式，而是把你自己在草稿纸上口算的动作，用字母写清楚。**

每次看到陌生题发懵，按这 **3 步把“人话”翻译成“数学式”**：
1. **先用具体小数字算 1 遍（落脚地面）**：比如先令 `N = 3` 或 `4`，拿具体数字口算一格答案（如“位置 3 到位置 1 颜色不同，距离是 `3 - 1 = 2`”），先彻底搞懂题目在干嘛。
2. **给刚才的数字起个字母外号（数字变字母）**：把具体位置 `3` 叫 `i`、另一个位置 `1` 叫 `j`，刚才那句口算就自动长成了数学表达：`在满足 C[j] ≠ C[i] 的位置里，找最小的 |i - j|`。
3. **看到难懂公式就代 2 组小数字验算（拆解“天书”）**：只要讲义里出现看不懂的公式（比如为什么切木头写 `(a - 1) / x` 而不是 `a / x`），立刻代一组**恰好整除**（`a = 10, x = 5`）和一组**不整除**（`a = 11, x = 5`）进去口算，10 秒钟就能把“天书”看穿！

## 一、考场实战探索 + 任氏数学搭桥「五步拆题骨架」

终点 100% 守住号家军 NOI 级严谨标准，起点落回考场真实的第一现场，把正确模型一步步“试”并“证”出来：

1. **第 ① 步 · 手玩小数据破冰 + 揪题眼陷阱（考场第一现场）**
   - 先拿 **`N = 3 ~ 4` 的具体小数字或画小图**手玩两步（遇到构造、博弈、操作等价题，大胆在草稿本上**列小表 / 穷举小例子**，肉眼捕捉重复、对称或抵消现象！）。
   - 同时圈出最易读歪的词：**子串**（连续）vs **子序列**（保持原序，禁先排序）vs **子集**（可重排）；求**原数总和**还是求**个数**；**最后一步是否退化**（如蜗牛爬井最后一天白天出井不再下滑）。
2. **第 ② 步 · 数字翻译成字母（亲手立出数学目标）**
   - 抓着第 ① 步刚算出来的具体数字算式，把具体数换成字母变量，用一句话立出清晰的数学目标与约束条件。
3. **第 ③ 步 · 自诊“哪步白干了” + 国内赛制分流（拒绝硬套菜单）**
   - 代入最大数据范围 `N`，对比 **1 秒 ≈ 1 亿次（10⁸）** 红线；但**不要盲目套模板**，先在小例子上往前多算一步（比如从第 3 个挪到第 4 个），用大白话问自己：**“哪一步在重复劳动 / 哪两个不同操作撞出了同一个结果？”**
   - **题型分流意识（国内 CSP-J/S & NOIP 实战）**：
     - **思维转化/优化题** → 看清重复劳动后，自然对接下方任老师「十大高频转化抓手」；
     - **DP / 图论难题** → 先立稳 **30~60 分朴素状态/暴力保底**，再盯着内层循环优化成 100 分（绝不贪心一步写挂拿 0 分）；
     - **搜索题** → 专注搜什么顺序、可行性剪枝与最优化剪枝；
     - **大模拟/表达式题** → 不需要数学转化，重点是把复杂规则拆成互不干扰的独立小函数。
4. **第 ④ 步 · 代数字慢放公式 + 可视化微证明（严密不超载）**
   - 对写出的转移方程或整除变形，**先代 2 组边界小数字算账验证**，再逐项说清每项物理含义。
   - **贪心或淘汰绝不靠瞎猜，用直观载体做 100% 严谨微证明**：
     - 排顺序 → **相邻两项交换对比**（直接推出 `sort` 比较式）；
     - 单调栈/队列 → **又老又差（或被挡死）永无出头之日**；
     - 选位置/区间贪心 → 在演草纸**画上下两行线段对比第 1 步余量**，并尝试**自己造一组 `N ≤ 3` 的刁钻反例推翻它**（推不翻且能说清“选端点绝不亏”即锁死！）。
5. **第 ⑤ 步 · 验毒四件套 + `N ≤ 5` 暴力对拍 + 回看懂原讲义**
   - 写码前过一遍下方「任氏验毒四件套」；
   - **考场零 WA 终极武器**：当正解逻辑较绕或已吃过 WA 时，花 3 分钟写一个 **5~10 行必对的朴素暴力**，在 `N ≤ 5` 小数据上跟自己的正解**本地对拍**，找出第一个结果不同的最小反例再交！
   - 做完后回看一眼任老师原讲义里的那句数学表达，确认“以前觉得难懂的式子，现在自己也能推出来了”，再挂上同门题名片。

## 二、任老师反复教的「十大高频建模转化抓手」

### 抓手 1：把问题挂到右端点（固定一端看另一端）
- **认题信号**：求满足某条件的区间 `[l, r]` 最值或个数，左右端点同时动眼花缭乱。
- **转化动作**：固定右端点 `r`（此时含 `r` 的项变成定值），只问“左边满足条件的 `l` 在哪个范围、最优是谁”。
- **课堂锚点**：
  - `PJ02-T3 合唱团排练`：区间和 `P[r] - P[l]` 最大且长度 `≤ L` ⇒ 固定 `r`，求窗口 `[r-L, r-1]` 内最小的 `P[l]`（单调队列）。
  - `ABC484-D Move One Card Left`：固定右端点 `r`（当 `A[r] ≠ A[r-1]`），合法左端点个数就是 `l < r` 中 `A[l] ≠ A[r]` 的数量 `r - cnt[A[r]]`。

### 抓手 2：翻转统计视角（从“枚举点对”改为“按边/元素算贡献”）
- **认题信号**：对所有点对 `(u, v)` 或所有子区间求某路径边权和 / 最大边权和，`N ≤ 10⁵` 无法 `O(N²)` 两两枚举。
- **转化动作**：别问每对点经过了哪些边，反过来问**“每一条边 `e`（或每个元素）被多少对点用到了？”** 总和 = `∑ (边权 w × 经过它的合法点对数)`。
- **课堂锚点**：
  - `PJ06-T6 树上染色`：删掉边 `e` 树分两侧，经过 `e` 的同色点对数 = `k(m-k) + (sz-k)(n-m-sz+k)`。
  - `PJ11-T5 路径最大边权之和` & `PJ05-T6 走廊泼水节`：边权升序 Kruskal 合并大小 `a, b` 的两块时，恰有 `a × b` 对点首次连通且路径最大边权就是 `w`，单步贡献 `w × a × b`。

### 抓手 3：先记账、后结算 & 逆序看最后一次定稿
- **认题信号**：`Q` 次区间整体加减最后问结果；或多次删除追加 / 全局覆盖涂色只问最终长什么样。
- **转化动作**：
  - **累加型（可叠加）**：一维差分两端记账 `d[l] += 1, d[r+1] -= 1`；二维差分四角容斥记账 `d[x1][y1]++, d[x2+1][y1]--, d[x1][y2+1]--, d[x2+1][y2+1]++`，最后一遍前缀和还原；或拆成时间轴 `+1 / -1` 事件排序扫描。
  - **覆盖型（后盖前）**：正着模拟会被后面推翻，改为**从后往前扫 `q = Q..1`**，第一次见到的状态就是最终定稿！
- **课堂锚点**：`PJ04-T2 活动覆盖`、`PJ09-T4 黑板擦写`、`ABC478-D 区间集合事件`、`ABC474-C Remove and Append`、`ABC477-D Masking Tape`。

### 抓手 4：倍数/定值差转同余 + 只记“最早位置”
- **认题信号**：连续子段和是 `K` 的倍数（或等于定值 / 落在 `[L, R]`）。
- **转化动作**：`P[r] - P[l]` 是 `K` 的倍数 ⇔ **`P[r]` 与 `P[l]` 模 `K` 余数相同**！要子段最长，每个余数只记**最早出现的前缀下标 `first[rem]`**。
- **必背验毒**：预登空前缀 `first[0] = 0`；含负数时 C++ 取模必须写 `((sum % k) + k) % k` 调回 `0 ~ k-1`。
- **课堂锚点**：`PJ06-T4 最长 K 倍区间`、`ABC484-E Subsegment Sum Finder`（前缀和差 + 树状数组）。

### 抓手 5：最值转单调判定 + 整数公式消灭浮点
- **认题信号**：“最大化最小值”（分蛋糕、树苗最小间距最大）或“最小化最大值”（切木头最长段最小）。
- **转化动作**：猜候选值 `x`，转化为判定问题 `feasible(x)`：“能不能做到……？”，利用单调性二分分界点。
- **任氏整数化神公式**：
  - 正整数向上取整：`⌈a / b⌉ = (a + b - 1) / b`；
  - 长 `a` 木头切成每段 `≤ x` 的最少刀数：`⌈a / x⌉ - 1 = ⌊(a - 1) / x⌋`（避免恰好整除时多切 1 刀！）；
  - 换最小单位消小数：时钟 `0.5°` 改用“半度”作单位（一整圈 `720` 半度），全程纯整数；
  - 连乘防爆 `long long`：判 `A₁A₂…Aₘ ≤ N` 改写为从 `s = N` 连续整除 `s /= Aᵢ` 看最终 `s > 0`。
- **课堂锚点**：`PJ02-T4 分蛋糕`、`PJ06-T5 树苗间隔`、`PJ11-T4 切木头`、`PJ05-T1 时钟角度`、`ABC480-E`。

### 抓手 6：贪心三板斧微证明（交换论证 / 画图对齐 / 遮挡淘汰）
- **认题信号**：需要决定处理顺序、安放位置或在数据结构中丢弃无用候选。
- **三大证明工具**：
  1. **相邻交换论证**：假设相邻两项反着放，写出交换前后的式子对比（如 `PJ07-T2 打印排队`、`PJ03-T6 紧急通知 max(i + tᵢ)` 先通知耗时长的子树、`PJ05-T5 小根堆拓扑序`）。
  2. **画图对齐比较 + 反例挑战**：上下两行画任意合法方案与贪心方案，对比第 `1..i` 个选择谁留给后面的空间更大（如 `PJ06-T5 树苗能种就种`、`PJ05-T2 右端点放浇水器`），再自造 `N ≤ 3` 刁钻小图试着推翻它。
  3. **遮挡淘汰论证**：元素 `A` 比 `B` 更早过期（或更靠右）且数值还不比 `B` 好 ⇒ `A` 永无出头之日，安全弹掉（`PJ10-T3 单调栈`、`PJ02-T3 单调队列`）。

### 抓手 7：状态瘦身（压掉无关历史，只留影响未来的最小信息）
- **认题信号**：顺序选子序列、带小参数约束的最短路、或树上全点求答案。
- **转化动作**：问自己“决定下一步能不能接上，我最少只需要记住什么？”
- **课堂锚点**：
  - `PJ04-T5 单词接龙`：链中间有哪些词毫不影响后续，只看末尾字母 ⇒ `O(N)` 压成 `dp[26]`；
  - `PJ02-T5 限时送达`：多一条“最多走 `K ≤ 20` 条路”硬限制 ⇒ 把已走边数收进状态 `d[t][v]`（必须先复制上一层再松弛！）；
  - `PJ02-T6 分组方案数`：盯第 `i` 个人仅两种去处（单独成组 `f[i-1][j-1]` vs 挑已有 `j` 组之一加入 `j·f[i-1][j]`）；
  - `PJ11-T6 换根 DP`：拆成 `子树内 down[u]` 与 `子树外 up[u]`，父亲预存 `best / second / best_child` 排除孩子自身贡献。

### 抓手 8：抓唯一代表元 / 极小操作防重复计数
- **认题信号**：不同操作或不同路径可能产生相同结果，要求“不重不漏计数”。
- **转化动作**：给每个合法结果绑定**唯一中心 / 最小质因子 / 极小操作区间**。
- **课堂锚点**：
  - `PJ09-T3 最长回文子串计数`：每个回文子串有唯一中心（`n` 个字符中心 + `n-1` 个间隙中心，共 `2n-1` 个）；
  - `PJ10-T5 欧拉线性筛`：`i % p == 0` 立刻 `break`，保证每个合数只被最小质因子筛一次；
  - `ABC484-C/D 抽牌插牌`：等价于区间 `[l, r]` 循环移位，收缩到首尾必异的**极小操作区间**（`A[l] ≠ A[r]` 且 `A[r] ≠ A[r-1]`），使不同区间与不同结果一一对应；
  - `PJ04-T4 幸运倍数` & `ABC483-E Typo Pairs`：算清每个对象在子集族中被重复数了几次，用容斥 / 二项式反演配系数使其恰计 1 次。

### 抓手 9：破环为序 & 高维压低维 / 行列解耦
- **认题信号**：围成一圈导致左右两趟扫描失灵；二维网格/矩阵枚举四条边 `O(N⁴)` 超时。
- **转化动作**：
  - **环形受邻约束**：环没有端点不能按位置扫，改为**按数值从低到高排序下标 `ord`**，小邻居必已定稿，天然无环（`PJ07-T3 环形分糖`）；
  - **二维压一维**：固定上下行边界 `[top, bot]`，把每列之和压成一维数组 `colsum[j]` 跑 Kadane 最大子段和（`PJ09-T5 最大子矩阵和`）；
  - **行列无关解耦**：行查询只看行坐标、列查询只看列坐标，拆成两个独立有序数组二分（`ABC482-C Band Count`）。

### 抓手 10：抽象关系建图 & 有限状态“尾链 + 循环节”
- **认题信号**：整数运算最少步数、两两等式/不等式/距离约束、或确定性规则走 `K ≤ 10¹⁸` 步。
- **转化动作**：
  - **操作建图**：数看成点、`+1/-1/×2` 看成边 ⇒ 无权最短路 BFS（`PJ07-T5 数字变换`）；
  - **染色/缩点建图**：树上距离为 2 ⇔ 二部染色同色 ⇒ 建约束图看连通块数 + 双星构造（`PJ04-T6 树`）；`A[u] ≤ A[v]` 与 `<` 建有向图求强连通分量 SCC（`ABC478-E`）；
  - **尾链 + 环取余**：`N` 个状态唯一后继走 `N+1` 步必重复，先扣入环前尾链 `s` 步再对环长 `L` 取余：`s + (K - s) % L`（`PJ11-T3 传送器`）。

## 三、写代码前 10 秒「任氏验毒四件套」+ 本地暴力对拍

1. **64 位溢出检查**：两个 `int` 相乘再赋给 `long long` 救不回中间溢出！必须在乘法开头写 `1LL * ...` 或操作数全开 `long long`。
2. **取整与二分中点检查**：求最大可行值用右倾中点 `(lo + hi + 1) / 2` 防死循环；求最小可行值用 `(lo + hi) / 2`；向上取整代一组“恰好整除”的数口算验毒（如 `10` 除以 `5`）。
3. **哨兵与退化边界检查**：全负数最大子段和初值设为 `a[0]` 绝不能设 `0`；不可达用 `LLONG_MIN / 4` 防加法下溢；前缀同余记得 `first[0] = 0`；检查 `N = 1`、`K = 0`、全相等。
4. **更新顺序与标记时机检查**：0/1 背包与树形背包容量**倒序**、完全背包容量**正序**；分层松弛先复制旧层；BFS **入队时立刻标 `dist`/`vis`**；`map` 滑窗频次减到 `0` 才 `erase`。
5. **考场防连交对拍法**：复杂贪心/计数/优化题交之前，写一个 5~10 行必对的暴力程序，随机造 100 组 `N ≤ 5` 小数据对比两者输出；只要对拍全过，再检查一遍大数 `long long`，几乎绝不盲吃 WA！
