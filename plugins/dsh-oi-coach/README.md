# `dsh-oi-coach` — 麒麒 OI 学习台（DeepSeek Harness 原生工作台插件）

零构建 ESM 原生 DeepSeek Harness 桌面插件（跨平台兼容 macOS 家长端与 Windows 孩子端），提供宽敞的 4 独立空间界面、物理只读权限隔离与官方 Antigravity CLI（`agy`）专家外脑直连。

## 一、 五个独立功能空间（`client.js`）
1. **💬 教练室（默认全屏首页）**
   - 100% 视口高度沉浸式对话空间 + 左侧可折叠**历史对话栏**（落盘于 `training/chat_history/*.json`，跨设备无缝续聊）；
   - 自动匹配 `training/problem_cache/` 与 `courses/notes/` 提供 **「📄 看原题」** 折叠抽屉、**「📚 对应讲义」** 与 **「🧑‍🏫 慢放拆解数学式」** 一键联动（首轮具体数字破冰零剧透、次轮同频号家军拆题脉络）；
   - 对话满 1 轮后支持顶栏 **「💾 存秘籍卡」** 一键抽取并落盘至 `mistakes/`。
2. **🎯 八级冲刺（12.26 GESP C++ 八级 80+ 直免 CSP-S 初赛专区）**
   - **80+ 战情仪**：实时统计距离 12.26 倒计时、客观卷折算分（目标 `≥ 44/50`）、编程真题点亮进度与模考合成总分；
   - **编程真题四母题棋盘**：26 道官方真题按最短路、最小生成树、组合数论、倍增树论分级，一键进入 `gesp8-coach` 双保险辅导模式（高档子任务保底 + 100% 正解）；
   - **客观题 44+ 特训 & 100分全真模考舱 & 四大模板排雷卡**：24 道六年级盲区互动微卡 + 11 套平时客观卷错题清零 + 2 套黑盒合卷防泄题模考 + 12 道模板细节找茬。
3. **📋 题单**
   - 按平台筛选清洗去重后的「近期待补题」与「隔月旧题冷启动重斩」，一键切入全屏教练室。
4. **🧮 建模练习（独立专区）**
   - **读题建模训练营（6 课交互实验）**：全高内嵌 `courses/math_lab/index.html` + 一键调起系统浏览器打印 A4 闯关单；
   - **专题建模快练（2 块破冰基石 + 号家军 10 法 × 3 档难度）**：演草纸走完「实战探索 + 数学搭桥 5 步法」；
   - **15 分钟手算微卡片（5 套）**：即时判分与标准术语挂牌。
5. **📚 错题与档案**
   - **我的通关秘籍**：展示 `mistakes/` 卡片墙（支持教科书分式与数学排版直读）；
   - **课程讲义**：置顶《号家军建模与六年级搭桥总纲》并展示全部 20 场普及模拟赛 / ABC 讲义，提供 **「🧑‍🏫 带我读懂数学推导」**（零打字点选具体题号慢放翻译）与「🎯 练 1 道变式建模题」；
   - **成长与同步**：动态统计四平台独立 AC 进度，顶栏内置 **「☁️ 自动同步」** 无感同步中心与 **「✨ 收到新升级，点此更新」** 胶囊（Windows 孩子端自动隐藏家长四平台抓题与模型下拉框）。

## 二、 物理权限隔离与双端护栏（`cordis.patch.yml` & `index.js`）
- `oi-coach`（麒麒 OI 教练）：`tool-fs` 物理只读（`write/edit/applyPatch: false`）、无 Shell 写权限；直连 `agy` 时运行在仓外隔离目录（不加载 `GEMINI.md`）并每轮强制注入反套话与「实战探索 + 数学搭桥 5 步法」护栏。
- `oi-parent`（OI 家长教研官）：Windows 下由 `cordis.patch.yml` 直接物理禁用；Mac 家长端需校验 `.env.local` 中的 `OI_PARENT_PIN` 口令方可访问。
